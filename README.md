# University Student Portal

A responsive University Student Portal frontend developed as part of my journey in learning web development.

This project demonstrates how HTML5 and CSS3 can be used to create a structured and user-friendly university portal interface.

## Features

- University header and navigation menu.
- Welcome and introduction section.
- Student dashboard with academic summary cards.
- Course cards with progress indicators.
- Academic results table.
- University announcements.
- Contact information section.
- Responsive layout for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS Media Queries

## Project Structure

```text
university-student-portal/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/abdiqaadirmahamed7/university-student-portal.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
